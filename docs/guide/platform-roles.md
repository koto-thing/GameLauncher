# 運営ロールとログイン

運営ロールはAdmin・幹部・幹部補佐です。GitHubユーザー名から本人を事前指定し、内部の数値IDと許可名の両方で認証します。一般利用者としての自動登録・ログインはありません。

| 操作 | 幹部補佐 | 幹部 | Admin |
| --- | --- | --- | --- |
| 全作品の公開・復旧、Uploader、Music管理 | 可 | 可 | 可 |
| 補佐の事前招待 | 不可 | 可 | 可 |
| 幹部の事前招待 | 不可 | 不可 | 可 |
| ロール変更・Admin昇格・許可取消 | 不可 | 不可 | 可 |
| 名前変更の再承認（元のロールを維持） | 不可 | 不可 | 可 |
| 設定 | 不可 | 可 | 可 |
| 危険操作 | 不可 | 不可 | 可 |

Cookieのロール、GitHub collaborator、旧policy_grants、Musicのadminフラグ・所属は許可根拠にしません。D1の最新ロールと事前許可を確認します。最後の有効Adminは通常のロール操作で削除できません。

詳細な認証境界、招待、名前変更の検知時間、既存10名を保持する移行・復旧手順は[運営専用GitHubログイン](operator-only-login.md)を参照してください。
