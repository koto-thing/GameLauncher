02 · Typeface

フォント案

今はフォントを指定していないため、WindowsではMS UI Gothic系にフォールバックし、細く字面が小さい状態になっている。3案とも SIL Open Font License 1.1 で、アプリへの同梱と再配布ができる。カードを押すと上のモックに反映される。

03 · Changes

改善ポイント

フォントを同梱して全体に適用

本文用と英数アクセント用の2書体を持つ。ページ見出しは800、本文は400〜500で、ウェイト差で階層を作る。

実装 QFontDatabase + QApplication::setFont

文字サイズの段階を整理

46 / 28 / 22 / 17 / 15 / 13 / 11px の7段に統一。見出しの上に小さな英字ラベル（RECOMMENDED など）を置き、何の画面かをひと目でわかるようにする。

実装 QSS objectName ごとの font-size

サイドバーにアイコンと選択中の面

「▦」の文字記号をやめ、3項目とも線画アイコンにそろえる。選択中は既存の selected 色で面を敷き、左端のアクセントバーはアニメーション付きのまま残す。

実装 SVGリソース + QPushButton::setIcon

トップのヒーローに情報を足す

サムネイル下部に暗いグラデーションを敷いてタイトルを重ね、右パネルにタグ・容量・バージョンと「詳細を見る」ボタンを置く。

実装 QPainter のグラデーション描画 + QLabel

ゲームカードのタイトルを画像の外へ

画像に黒帯を重ねる方式をやめ、タイトルと補足を画像の下に出す。画像が隠れず、長いタイトルも読める。所持済みには小さなバッジを付ける。

実装 GameCardDelegate::paint の変更

詳細画面の可読性

背景モデルの上に左下からのスクリムを敷き、白文字のコントラストを確保する。お知らせは日付付きの横並びカードに、進捗は細いバーと速度・残り時間の数値表示にする。

実装 GameDetailPage の重ね描き + QSS

ボタンと入力欄の形をそろえる

角丸を 10px 系に統一し、アカウント・設定は円形のアイコンボタンに。検索欄には虫眼鏡アイコンを付ける。

実装 QSS + QLineEdit::addAction

キーボード操作時のフォーカス表示

Tab移動中の要素にアクセント色の枠を出す。今はフォーカス位置が見えにくい。

実装 QSS :focus

05 · Next

実装の進め方

  1. フォントだけ先に入れる。選んだ書体を apps/launcher/resources/fonts/ に置いて resources.qrc に登録し、起動時に QFontDatabase::addApplicationFont で読み込んで QApplication::setFont する。これだけで全画面の見え方が変わる。
  2. 文字サイズとウェイトを整える。applyTheme() のQSSで見出し・本文・補足のサイズを7段にそろえ、英数ラベルに font-family でアクセント書体を当てる。
  3. サイドバーとヘッダー。アイコンSVGを追加し、4画面で重複しているヘッダー生成を1つの関数にまとめる。
  4. カードとトップのヒーロー。GameCardDelegate と home page のレイアウトを変更する。
  5. 詳細画面。スクリム、お知らせ、進捗表示を変更する。

フォント同梱に伴い THIRD_PARTY_NOTICES.md にOFLの表記を追加する。日本語フォントはファイルが大きいので、インストーラーのサイズが増える。
