# 作品ページのGLSL背景

作品編集の「GLSL背景」にコードを入力し、「コンパイルして適用」でプレビューします。成功後に下書きを保存し、作品を公開すると作品ページと曲ページに反映されます。構文エラー・リンクエラーはコード欄の下に表示され、適用済みのコードは変更されません。「編集を取り消す」で入力を戻せます。

WebGL 1 / GLSL ES 1.00 のフラグメントシェーダーを使います。Shadertoy風の `mainImage(out vec4 fragColor, in vec2 fragCoord)` を定義してください。ホストが `main`、精度宣言、次のuniformを追加するので、それらの宣言は不要です。

- `iTime`: float。表示中の経過秒。動きを抑える端末設定では0。
- `iResolution`: vec3。実際の描画バッファの幅、高さ、1。解像度は縦横比を保って最大1920×1080に制限します。

```glsl
void mainImage(out vec4 fragColor, in vec2 fragCoord) {
    vec2 uv = fragCoord / iResolution.xy;
    fragColor = vec4(uv, 0.5 + 0.5 * sin(iTime), 1.0);
}
```

アルファ値を1未満にすると背景色・画像が透けます。GLSL背景は本文パネルまで表示されます。描画された背景と背景色・画像を16×16画素に合成し、約1秒ごとに平均相対輝度を確認します。明るい背景には濃い文字と明るいシャドウ、暗い背景には白い文字と暗いシャドウを使います。ボタン・再生波形も配色が切り替わります。明暗の切替には幅を持たせてちらつきを抑えます。局所的に明暗が激しく混在するコードでは、文字の背後の模様も調整してください。

テクスチャ入力、iMouse、複数パス、頂点シェーダーの編集、JavaScriptの実行には対応していません。Shadertoyの全機能との互換性はありません。

コードは最大16000 UTF-16コード単位です。サーバーは文字数と型を検証し、ソースをJSON文字列として保持します。コンパイルはブラウザーのWebGLで行います。公開先端末でコンパイルできない場合は背景色・画像が表示されます。画面外・非表示タブではアニメーションを停止します。GPU負荷はコードによって変わるため、複雑なシェーダーは対象端末でも確認してください。

仕様: https://registry.khronos.org/webgl/specs/latest/1.0/index.html
