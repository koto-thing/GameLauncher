# Music管理の本人確認

Music管理は管理サイト共通の運営許可を使います。Admin・幹部・幹部補佐が対象です。事前指定のないGitHub本人、取消済み本人、招待受諾前の限定Cookieには管理・アップロード・bridge操作を許可しません。

本人の固定GitHub数値IDをmusic_accountsの外部キー参照にも使います。招待受諾時に本人行を共通D1の同一トランザクションで作成します。music_accounts.adminとmusic_membershipsはログイン許可や共通運営権限の根拠にはしません。

一般公開のカタログ・再生・素材配信は引き続き公開PHPが担当します。管理サイトのログイン制限は公開配信を閉じません。bridgeは従来どおり管理Workerからの用途限定署名要求だけを受け付けます。

[運営専用ログインと移行手順](../guide/operator-only-login.md)を参照してください。
