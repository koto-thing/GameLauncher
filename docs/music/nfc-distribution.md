# NFCアクキーの配布

コマンドコードは曲（`tracks/{trackId}`）、NFCアクキーは作品（`games/{gameId}`）へリンクします。作品編集画面の「アクキー配布（NFC）」で公開サイトの作品URLをコピーできます。管理画面のURLを書き込まないでください。

1. NDEF対応タグを用意します。NTAG213/215/216のユーザーメモリは144/504/888バイトです。実際のURLとNDEFレコードが収まる容量を選びます。
2. スマートフォンのNFC書き込みアプリでURL / URIレコードを1件作成し、コピーした作品URLを書き込みます。同じ作品の配布物には同じURLを使います。
3. 作品を公開し、アクリルへ組み込んだ完成品を対応iPhone・Androidで読み取り、作品ページと収録曲の再生を確認します。金具を付けた状態でも確認してください。
4. 正しい本番URLであることを検品した後、必要に応じて読み取り専用にロックします。ロックは元に戻せません。

タグに音源や認証情報は保存しません。公開ページの閲覧には通信が必要です。限定所有権やコピー防止の仕組みではありません。非公開・運営停止中の作品は開けません。配布後は同じドメインと作品IDを維持してください。

Webサイトからタグへ直接書き込む機能はありません。タグの書き込みは専用アプリで行い、受け取った人は端末のNFC読み取りからURLを開きます。対応端末の条件はメーカーの仕様をご確認ください。

## WebGLスナップショット

作品編集画面でGLSLをコンパイルして適用すると、ページデザインのプレビューに「WebGLのスナップショットを保存」が表示されます。現在のWebGL描画をPNGで保存します。背景色・背景画像・本文は含まず、シェーダーの透過を維持します。下書き保存・公開前でも利用できます。解像度はプレビューの描画サイズ（最大1920×1080）です。
