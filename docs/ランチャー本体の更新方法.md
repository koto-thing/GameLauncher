## 5. ステージングワークフローを実行する

GitHub Actionsからつぎを実行する
```txt
Publish Windows staging
Version: 1.0.1
```

次の3箇所を必ず同じバージョンにする
```txt
CMakeLists.txt                       1.0.1
services/distribution-content/content/launcher/release.*   1.0.1
Workflow input                       1.0.1
```

## 6. 既存のランチャーから更新する

新しいインストーラーを使わず、すでにインストール済みのランチャーを起動する。  
設定画面の「更新と通知」から更新確認を実行して、最新のバージョンが表示されたらアップデートする。  
Maintenance Tool が起動し、ランチャーが終了するのが正常動作。  

更新後に確認する項目：  
* ランチャー表示バージョンが `最新バージョン` になっている
* カタログが表示される
* インストール済みゲーム情報が残っている
* ゲームが起動する
* 設定が保持されている
* `maintenancetool.exe` が引き続き存在する
